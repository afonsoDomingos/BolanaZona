# ⚽ Bola na Zona

Plataforma premium para gestão de torneios de futebol de bairro.

## 🚀 Funcionalidades
- **Gestão de Torneios**: Criação de torneios mata-mata ou fase de grupos.
- **Equipas e Jogadores**: Registo completo de equipas, capitães e jogadores.
- **Calendário Automático**: Geração automática de jogos com algoritmos de Round Robin.
- **Classificação Dinâmica**: Tabelas de pontos atualizadas em tempo real.
- **Páginas Públicas**: Links partilháveis para que todos possam acompanhar o torneio.

## 🛠️ Tecnologias
- **Frontend**: React, Vite, Lucide React, Axios.
- **Backend**: Node.js, Express, Mongoose.
- **Base de Dados**: MongoDB Atlas.
- **Uploads**: Cloudinary.
- **Estilos**: Vanilla CSS (Premium Dark Theme).

## 📦 Como Instalar
1. Clone o repositório:
   ```bash
   git clone https://github.com/afonsoDomingos/BolanaZona.git
   ```
2. Instale as dependências na raiz:
   ```bash
   npm run install-all
   ```
3. Configure os ficheiros `.env` no `client` e no `server` (veja `.env.example`).
4. Inicie o projeto:
   ```bash
   npm run dev
   ```
